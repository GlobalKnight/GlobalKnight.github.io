AntiViral

Antiviral takes place on the user's PC in more ways than one. The theme of the game is to guide a virus infecting your computer into a terminating collection by placing antiviral nodes to guide it along its path. The virus itself was implemented using the Boids flocking algorithm to create a naturally chaotic yet organized path. This project was created using a mix of C and C++, along with my college's own library.

Gameplay Engineering

My role in the gameplay implementation for this project was to implement logic for the game's main losing condition and to create objects that shape how the game works. To create the losing condition, I set counters and a threshold for how many virus members escaped into the player's computer. By setting a threshold for how many virus units hit obstacles or run off the screen, we easily had the condition in place that each level could set individually. This also added a stretch goal for scoring how well the player performed.

Audio Pipeline

Additionally, my focus on the team was integrating the audio pipeline, using FMOD, into our game. I oversaw the gathering of audio assets and implemented them in the correct places inside the game. That included SFX and music files, all triggered and placed at their opportune timings within the code.

	void Obstacle::Update(float dt)
	{
	  UNREFERENCED_PARAMETER(dt);
	  if (CheckIfWon(boidList))
	  {
	    return;
	  }
	  else
	  {
		int temp = capturedBoids;
		capturedBoids += CheckBoidCollisions(boidList, TransformGetPosition(transform), TransformGetScale(transform), KillBoid);
		RestartCount = capturedBoids;

		if (capturedBoids < totalBoids - 2 && !won && temp < capturedBoids)
		{
		  PlayEscapedSound();
		}
		else if (capturedBoids >= totalBoids - 2 && !won)
		{	
		  won = true;
		}
	  }
	}
