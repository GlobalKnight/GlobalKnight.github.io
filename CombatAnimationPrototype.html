Spring 2023

2D Combat Prototype

I started this Unity project to see how far I could get into a megalovania-style game over the course of a summer. I was going through the first Castlevania game at the time and used it as a reference on how to progress, but I wanted to incorporate combo attacks into its move set and build upon that. The point I got to in the project was enough to make animations for two-step combos alternating between the uses of light and heavy attacks, but with room for iteration. I also made a burst fire attack and a fire stream attack to create a potential magic system later.

Animation

I took the last few weeks of a summer to work on this project and was able to learn more about working with an art pipeline in Unity and how to create animation assets. With even more insight into how to work with Unity's animation graph, I created a graph that managed each of the player's states, including attacking actions, walking, crouching, and jumping. The graph itself became messy as a first experience with it, but I designed it to ensure that each step of the process could be completed and return to its idle state.

I'm not very trained in digital art, and this was my first attempt at making animations, so I worked on a basis of ensuring that the animations could be stylistically choppy and still smooth where it matters to accommodate for that detail, while it's still in a very early development stage as a prototype. I created every asset in Aseprite for sprite sheets and used Unity's tools to cut them into animations for playing.

Gameplay Logic

The logic for this prototype is simple, involving only input controls, gravity settings, and a small tile map to keep the space contained for the project. The input in the player's script for attacks is just checking for the first input, whether a heavy or light, and then all sequential inputs are checked inside the animation graph itself.
